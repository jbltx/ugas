[Added] Machine-readable packaging for programmatic/agent consumers (P0 of the Unity Studio integration feedback):

- **`{version}/index.json`** — a checksummed resource manifest enumerating every published resource (`id`, `kind`, `title`, `path`, canonical `url`, `mediaType`, `bytes`, `sha256`), generated by `scripts/build_manifest.py`.
- **`{version}/sections/*.md` + `{version}/sections/index.json`** — the spec pre-chunked into individually-addressable sections with stable, renumber-tolerant ids (derived from the heading slug), generated by `scripts/build_sections.py`. `SPEC.md` is unchanged.
- **`llms.txt` is now generated from the manifest** (`scripts/build_llms_txt.py`) instead of hand-maintained, so it can no longer drift — it now lists all 10 genre packs and all 11 schemas (previously 3 and 6). The hand-maintained root `llms.txt` is removed.
- **`schemas/manifest/*.schema.json`** — meta-schemas so consumers can validate the manifests they vendor.
- CI: `publish-docs`/`preview-docs` run the new generators (`scripts/build-artifacts.sh`) and verify them (`scripts/check_artifacts.py`); `validate-schema-examples` guards against a re-committed `llms.txt` and malformed meta-schemas.
