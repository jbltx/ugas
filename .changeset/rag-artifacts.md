[Added] RAG retrieval artifacts (P2 of the Unity Studio integration feedback):

- **`{version}/rag/chunks.jsonl`** — finer, `###`-subsection-level chunks (one JSON object per line: `id`, `version`, `pillar`, `sectionId`, `headingPath`, `anchor`, `sourceUrl`, `tokens`, `sha256`, `text`). Oversized subsections split on `####` then blank lines, and **never inside a fenced code/YAML block**, so entity and schema fragments stay whole. Generated by `scripts/build_rag.py`.
- **`{version}/rag/llms-index.json`** — a curated author-intent → chunk-id map ("author an effect", "modifier pipeline", "gate an ability on state", …) resolved against the generated chunks, so consumers can route without embeddings and seed retrieval for those that use them.
- Meta-schema `schemas/manifest/rag-chunk.schema.json`; `check_artifacts.py` validates every chunk against it, verifies no chunk splits a fence, checksums match, and every `llms-index` id resolves.
