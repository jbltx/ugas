[Added] Offline-resolvable schema bundle and a conformance corpus (P1 of the Unity Studio integration feedback):

- **`{version}/schemas/bundle.json`** — a single self-contained JSON-Schema document with every entity type under `$defs` and all internal `$ref`s rewritten to resolve with no network. A top-level `allOf` of `if`/`then` clauses dispatches on the entity's own `$schema`, so a consumer can validate any UGAS entity against the one file, fully offline. Generated by `scripts/build_schema_bundle.py`.
- [Changed] `attribute_set` schema now uses `$defs` instead of legacy `definitions`, so `$defs` usage is consistent across all schemas.
- **`conformance/valid/` + `conformance/invalid/`** — a labelled corpus (5 valid, 7 invalid) covering missing-required, bad-enum, placeholder-scalar, and nested-modifier violations. `scripts/run_conformance.py` asserts every valid entity passes and every invalid entity is rejected through the bundle, and is wired into CI. Consumers can run the same corpus against their own loader/validator.
- `check_artifacts.py` now also verifies the bundle is a valid, offline-resolvable schema; the resource manifest enumerates the bundle and corpus; publish/preview stage and version-stamp `conformance/`.
